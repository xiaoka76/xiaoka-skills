# 官方《Seedream 4.0-5.0 提示词指南》要点

来源：[Seedream 4.0-5.0 提示词指南](https://www.volcengine.com/docs/82379/1829186)（火山方舟官方文档）

> **官方适用范围**：该指南原文标注适用于 **Seedream 5.0 lite / 4.5 / 4.0**；5.0 pro 的《图片生成 API》
> 文档把「提示词指南」指向的也是这一篇，因此可作为 pro 的参考。但**「多图输出（组图）」那一节
> 不适用于 5.0 pro**——pro 明确不支持组图，见文末「与 5.0 pro 的差异」。

本文是官方指南的要点提炼，配合 `prompt-writing.md`（JSON 模板方法论）一起用：前者是**写提示词的官方规则**，
后者是**把画面拆成结构化模板**的方法。

---

# 一、通用规则（5 条）

## 1. 用自然语言清晰描述画面

用**简洁连贯**的自然语言写明 **主体 + 行为 + 环境**；若对美学有要求，再用自然语言或短语补充
**风格 / 色彩 / 光影 / 构图**。

| | 写法 |
|---|---|
| ✅ 推荐 | 一个穿着华丽服装的女孩，撑着遮阳伞走在林荫道上，莫奈油画风格。 |
| ❌ 避免 | 一个女孩，撑伞，林荫街道，油画般的细腻笔触。 |

> 差别不在于"字多字少"，而在于**前者是连贯的一句话，后者是把词堆在一起**。官方明确：
> 这几代模型理解力更强，**在较少描述的情况下也能生成符合预期的画面**，且画面不再泛白，
> 因此**简洁精确的提示通常优于重复堆叠华丽复杂的词汇**。

## 2. 明确应用场景和用途

有明确用途时，把**图像用途和类型**写进提示词。

| | 写法 |
|---|---|
| ✅ 推荐 | 设计一个游戏公司的 logo，主体是一只在用游戏手柄打游戏的狗，logo 上写有公司名 "PITBULL"。 |
| ❌ 避免 | 一张抽象图片，狗拿着游戏手柄，狗狗上写 PITBULL。 |

## 3. 提升风格渲染效果

有明确风格需求时，使用**精准的风格词**，或提供**参考图像**。

## 4. 提高文本渲染准确度

要生成的**文字内容放进双引号**里。

| | 写法 |
|---|---|
| ✅ 推荐 | 生成一张海报，标题为 "Seedream 4.5" |
| ❌ 避免 | 生成一张海报，标题为 Seedream 4.5 |

## 5. 明确编辑目标与"希望保持不变的部分"

用**简洁明确的指令**说明修改/参考的对象及具体操作，**避免指代模糊的代词**；
如果除修改内容外都希望保持不变，就在提示词里显式强调。

| | 写法 |
|---|---|
| ✅ 推荐 | 让图中最高的那只熊猫穿上粉色的京剧服饰并戴上头饰，并保持动作不变。 |
| ❌ 避免 | 让它穿上粉色衣服。 |

# 二、文生图

- 采用清晰明确的自然语言描述画面内容；细节丰富的图像，用**详细文本精准控制画面细节**。
- 知识/推理类内容（公式、图表、教学插图）：明确使用**专业术语**保证表达准确，并写清对图像的
  具体要求——可视化形式、版式、风格。

官方示例（结构化但仍是连贯自然语言）：

```
一个凌乱的办公桌桌面。桌面上有一台开着的笔记本电脑，屏幕显示绿色代码；旁边一个马克杯，
杯上写着 "Developer"，杯口冒出热气；一本摊开的书，页面是维恩图，展示三个圆的嵌套关系…… 
背景是模糊的书架。阳光从右侧照射，在桌上形成光影。
```

```
绘制一张信息图，展示通货膨胀的成因，每条成因独立呈现，并配有简洁图标。
```

# 三、图生图

模型支持结合文本与图片完成图像编辑与参考生成，并可用**箭头、线框、涂鸦等视觉信号**控制画面区域。

## 3.1 图像编辑

支持 **增加 / 删除 / 替换 / 修改** 四类操作。用**简洁明确**的文字，**准确指示要编辑的对象与变化要求**。

| 场景 | 官方 prompt 示例 |
|------|-----------------|
| 增加 | 给图中女生增加相同款式的银色耳线和项链。 |
| 删除 | 去掉女生的帽子。 |
| 替换 | 把最大的面包人换成牛角包形象，保持动作和表情不变。 |
| 修改 | 让图中三个机器人变成透明水晶材质，颜色从左到右分别变成红黄绿。并让绿色的机器人跑起来，黄色的走路，红色的站立。 |

**画面复杂、难以用文本准确描述编辑对象时**，用箭头 / 线框 / 涂鸦指明对象和位置：

| 方式 | 官方 prompt 示例 |
|------|-----------------|
| 涂鸦 | 将房间内红色涂抹位置放入电视，蓝色涂抹位置放入沙发，不改变其他布局，确保放入物体和整张图的原木风格一致。 |
| 线框 | 放大图中的标题至红框大小，并改成和萨克斯图案一样的颜色和字体风格。 |

> 这与交互编辑的「任意标记 + 自然语言」是同一套思路：**用视觉标记指位置，用文字说意图**。
> 本技能的 `seedream mark --plain` 产出的彩色标记图正好可以直接当这类输入。
> 而如果是**坐标式**编辑，更稳的做法是**先用图层拆分拿到精确区域**——图层拆分给出的
> `prompt_fragment`（`<bbox>` 标签）可直接用，不必自己量坐标。见 SKILL.md「坐标口径」章节。

## 3.2 参考图生图

从参考图中提取关键信息（**人物形象 / 艺术风格 / 产品特征**），做角色创作、风格迁移、产品设计。

提示词只需写清**两部分**：

1. **指明参考对象**——想从参考图里提取并保留什么（参考图中的人物形象、参考图中产品材质……）
2. **描述生成画面**——想生成的内容、场景等细节

官方示例：

```
参考图中的人物形象，做一个动漫人物手办，放在桌上，后面放置一个印有角色图像的生日礼物包装盒，
盒子下面有一本书……将场景设置在室内，尽可能真实；生成尺寸和现在图一样；手办在图片的左边；
整个图片的风格和原始图一样，大片摄影感。
```

```
参考图标的线性简约风格，设计 9 个不同场景下的应用 icon，包括：音乐、天气、日历、相机、聊天、
地图、闹钟、购物车、笔记本，保持一致的配色。
```

```
生成四件不同材质和颜色的上衣，衣服款式与图中女生身上的衣服一致，只要衣服，不要模特。
```

**从设计草图生成高保真效果图**（平面图、线稿图、手绘原型）时，遵循三条：

1. 提供**清晰的原始图片**；图中若有文字说明，在提示词里注明"**遵循图中文字内容进行生成**"
2. **明确主体与要求**，如"高保真 UI 界面""现代简约风格客厅实景图"
3. **明确指出需与参考图保持一致的关键要求**，如"家具位置与参考图一致""按照原型图的布局"

官方示例：

```
这是一个 Web 端房屋租赁软件的详情页手绘图，请根据图中文字示意，将其渲染成高保真的 UI 界面，
并在画廊区域增加一些示例图片，在房屋信息和预定信息区域增加一些示例的文字信息。
```

# 四、多图输入

同时输入多张图，完成**替换 / 组合 / 迁移**等复合编辑。提示词里要**清楚指明不同图像各自要编辑/参考的对象**。

| 场景 | 官方 prompt 示例 |
|------|-----------------|
| 替换 | 将图一的主体替换为图二的主体。 |
| 组合 | 让图一人物穿上图二的服装。 |
| 迁移 | 参考图二的风格，对图一进行风格转换。 |

> 官方句式是"**图一 / 图二**"；本技能 SKILL.md 里用"图1 / 图2"，两者是一回事，保持同一段提示词里
> 用词一致即可。

# 五、与 5.0 pro 的差异（重要）

| 能力 | 官方指南（5.0 lite / 4.5 / 4.0） | Seedream 5.0 pro |
|------|--------------------------------|------------------|
| 文生图 / 图生图 / 参考图生图 | ✅ | ✅ |
| 图像编辑（增删改替） | ✅ | ✅ |
| 箭头 / 线框 / 涂鸦视觉信号 | ✅ | ✅ |
| 多图输入（替换/组合/迁移） | ✅ | ✅ |
| **多图输出（组图）** | ✅（"一系列""一套""组图"触发） | ❌ **不支持**，见《图片生成 API》 |
| 联网搜索 | 5.0 lite 支持 | ❌ 不支持 |
| 流式输出 | ✅ | ❌ 不支持 |

> 组图那节（"生成四张图，影视分镜……"、"生成周一到周日共七张手机壁纸图……"）**不要用于 5.0 pro**，
> pro 只会出单图。需要组图请改用 5.0 lite。

# 六、和本技能既有规范的差异提示

本技能 SKILL.md 的「Agent 使用规范」出于"简短提示词容易画面空洞"的经验，要求文生图提示词
**必须覆盖 6 个维度、至少 80-150 字**。官方指南的口径略有不同：**简洁精确优于堆砌华丽词汇**，
且这几代模型在较少描述下也能生成符合预期的画面。

两者并不完全冲突（官方反对的是"堆叠华丽复杂的词汇"，不是"信息完整"），但**取舍应由使用者决定**：

- 想要**信息完整**：按 SKILL.md 的 6 维度展开，但用**连贯自然语言**写，不要罗列词块；
- 想要**简洁精确**：抓住"主体 + 行为 + 环境"写清楚，美学需求用精准风格词补一句。

无论选哪种，上面**通用规则 1-5 都是硬要求**（尤其：文字加双引号、避免模糊代词、显式声明要保留的部分）。
